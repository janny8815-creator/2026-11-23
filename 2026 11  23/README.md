# 간호실습 메이트 (실습일지·사례보고서 AI 피드백 도우미)

간호학과 1학년 학생이 임상실습 보고서(**실습일지**, **사례보고서(Case Study)**) 작성을 미리 연습하고 정밀 피드백을 받을 수 있는 정적 웹 애플리케이션입니다.

## 주요 기능
- **보안 BYOK API 키 설정 바**: 본인 Gemini API 키를 브라우저 `localStorage`에만 저장(코드 내 하드코딩 없음)
- **2개 메인 작성 탭**: 실습일지 도우미 / 사례보고서(Case Study) 도우미
- **1학년 맞춤 학습 보조**: 항목별 `?` 개념 도움말, `[예시 데이터 채우기]` 버튼
- **실시간 개인정보(비식별화) 사전 경고**: 주민등록번호·전화번호·병원등록번호 의심 패턴 즉시 감지
- **AI 2트랙 정밀 분석 (`gemini-2.5-flash`)**:
  1. 부족한 점 피드백 (교정)
  2. 추가할 내용 선제안 (먼저 추천)
  3. 1학년용 쉬운 용어 풀이
  4. 항목별 완성도 체크리스트 + 전체 완성도 점수
- **초안 자동 저장 / 결과 복사 / 인쇄(PDF 저장)**

## 로컬 실행 방법
```bash
npm install
npm run dev
```

## 정적 빌드 및 Netlify 배포
```bash
npm run build
```
- GitHub 저장소에 푸시한 뒤 Netlify에서 저장소를 연결하면 `netlify.toml` 설정(`npm run build` → `dist`)으로 바로 정적 배포됩니다.
